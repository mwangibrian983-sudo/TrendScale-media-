How to Launch TrendScale Media for $0

Follow these exact step-by-step instructions to get your free Gemini API key, deploy your website to GitHub/Vercel for zero hosting costs, and hook up IntaSend for real M-Pesa payouts.

1

Get Your Free Google Gemini API Key

Google provides a generous free tier for Gemini 3 Flash that allows hundreds of article generations per day without requiring a credit card.

  1. Visit aistudio.google.com and sign in with your Google account.
  2. Click "Get API Key" -> "Create API Key in New Project".
  3. Copy the API key string and paste it into your TrendScale Media Control Center dashboard.
2

Host Your Site for Free on Vercel or GitHub Pages

You don't need paid server hosting. Static web platforms run on global Edge networks for $0/month.

  1. Create a free account at GitHub.com.
  2. Save this index.html code into a repository named trendscale-media.
  3. Connect your GitHub account to Vercel.com and click "Import Repository".
  4. Click "Deploy". Your site is now live globally with free SSL security!
3

Connect IntaSend Kenya for M-Pesa Settlements

IntaSend allows you to accept international card payments and ad income, routing settlements directly to your Safaricom M-Pesa line.

  1. Register at IntaSend.com (Zero signup fees).
  2. Go to Settings -> API Keys to find your Secret and Publishable keys.
  3. Add your M-Pesa phone number (2547XXXXXXXX) in the Payouts settings tab.
  4. Whenever your Google AdSense or affiliate revenue clears, IntaSend automatically triggers instant B2C transfers to your mobile phone.
